- [Execute a function using the GET method](operations/executeFunctionUsingGet/operation.md)
  - To execute a standalone function that is exposed as a REST API, using an OAuth access token and the HTTP GET method. OAuth 2.0 must be enabled for the REST API endpoint of the function.
  - [Examples](operations/executeFunctionUsingGet/examples/)

  - [Examples](operations/executeFunctionUsingPost/examples/)
