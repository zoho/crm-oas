# Kiosk Get Records API

- [OpenAPI specification](kiosks_get_records.yaml)
- [Kiosk GetRecords](operations/getAllKioskGetRecords/operation.md)
  - To retrieve all GetRecords configurations associated with a Kiosk. The response includes details such as criteria, selection configuration, selected fields, module information, and sorting preferences. Use the [Get All Kiosks API](kiosks.yaml#$.paths./settings/kiosks.get) to retrieve the Kiosk ID.
  - [Examples](operations/getAllKioskGetRecords/examples/)
- [Kiosk GetRecord](operations/createKioskGetRecord/operation.md)
  - To create a [GetRecords](https://help.zoho.com/portal/en/kb/crm/customize-crm-account/kiosk/articles/elements-of-a-kiosk#GetRecords) configuration associated with a Kiosk. It defines how records should be fetched from a module, including criteria, selection behavior, and sorting. Use the [Get All Kiosks API](kiosks.yaml#$.paths./settings/kiosks.get) to retrieve the Kiosk ID. **Note:** - You can configure GetRecords only for Kiosks in the draft state. - The maximum number of GetRecords configurations allowed per Kiosk depends on the CRM edition: - Enterprise: 50 - Professional: 10 - Standard: 5
  - [Examples](operations/createKioskGetRecord/examples/)
- [Retrieve a specific get_record component from a Kiosk](operations/getKioskGetRecord/operation.md)
  - To retrieve the details of a specific GetRecords configuration associated with a Kiosk using its GetRecords ID. Use the [Get All Kiosks API](kiosks.yaml#$.paths./settings/kiosks.get) to retrieve the Kiosk ID and the Kiosk GetRecords API to retrieve the GetRecords ID. **Note:** The response structure is dynamic and depends on the GetRecords configuration. Fields such as criteria, type, and selection_details may vary based on the configured settings.
  - [Examples](operations/getKioskGetRecord/examples/)
- [Kiosk GetRecord](operations/updateKioskGetRecord/operation.md)
  - To update an existing [GetRecords](https://help.zoho.com/portal/en/kb/crm/customize-crm-account/kiosk/articles/elements-of-a-kiosk#GetRecords) configuration associated with a Kiosk. This API supports only draft Kiosks. You can update the following fields: - name - criteria - sort_order - result_type - limit Use the [Get All Kiosks API](kiosks.yaml#$.paths./settings/kiosks.get) to retrieve the Kiosk ID and use the Kiosk GetRecords API to retrieve the available GetRecords configurations for a Kiosk. **Note:** This API won't work for the Active Kiosks. The system will throw the **NOT_ALLOWED** error.
  - [Examples](operations/updateKioskGetRecord/examples/)
- [Kiosk GetRecord](operations/deleteKioskGetRecord/operation.md)
  - To delete a specific [GetRecords](https://help.zoho.com/portal/en/kb/crm/customize-crm-account/kiosk/articles/elements-of-a-kiosk#GetRecords) configuration associated with a Kiosk. Use the [GetRecords Associations API](kiosks_get_records.yaml#$.paths./settings/kiosks/{kioskId}/get_records/{getRecordId}/associations.get) to identify all associations of the GetRecords configuration. Remove the associations from the respective Kiosk components, and then delete the GetRecords configuration. Use the [Get All Kiosks API](kiosks.yaml#$.paths./settings/kiosks.get) to retrieve the Kiosk ID and use the [Kiosk GetRecords API](kiosks_get_records.yaml#$.paths./settings/kiosks/{kioskId}/get_records.get) to retrieve the GetRecords ID. **Note:** The response structure is dynamic and depends on the GetRecords configuration. Fields such as criteria, type, and selection_details may vary based on the configured settings.
  - [Examples](operations/deleteKioskGetRecord/examples/)
- [GetRecords Associations](operations/getKioskGetRecordAssociations/operation.md)
  - This API returns all the associations of a specific [GetRecords](https://help.zoho.com/portal/en/kb/crm/customize-crm-account/kiosk/articles/elements-of-a-kiosk#GetRecords) configuration. Associations represent where the configuration is being used, such as: - Kiosk states - Actions - Other dependent elements This API helps you understand the dependencies of a GetRecords configuration before [modifying](kiosks_states.yaml#$.paths./settings/kiosks/{kioskId}/states/{stateId}.put) or [deleting](kiosks_states.yaml#$.paths./settings/kiosks/{kioskId}/states/{stateId}.delete) it. **Note:** Predefined states, start state and end state, cannot be deleted.
  - [Examples](operations/getKioskGetRecordAssociations/examples/)
- [Get Kiosk Associations](operations/getKioskAssociations/operation.md)
  - Retrieves all associations configured for a specific Kiosk in Zoho CRM, including the associated resources and, their additional details. Use the [Get All Kiosks API](kiosks.yaml#$.paths./settings/kiosks.get) to retrieve the Kiosk ID. **Note:** - The structure of each resource object is mostly consistent, but _details can vary. - The sequence_number plays an important role in determining execution or display order.
  - [Examples](operations/getKioskAssociations/examples/)
- [Kiosk Associations](operations/updateKioskAssociations/operation.md)
  - This API allows you to associate an active Kiosk with the Record Detail View Page of a module. Once associated, the Kiosk will be available within the selected module's Record Detail View Page based on the specified layout. Use the [Get All Kiosks API](kiosks.yaml#$.paths./settings/kiosks.get) to retrieve the Kiosk ID. Ensure that the Kiosk is in the active state before associating it. **Note:** - To delete an existing association, include the _delete key with a null value ("_delete": null) in the request. Refer to the Sample input to disassociate a Kiosk from the Record Detail View Page for an example. Specify the association id to remove the Record Detail View Page association. Use the [Kiosk Associations API](kiosks_get_records.yaml#$.paths./settings/kiosks/associations.get) to retrieve the ID. - The maximum number of Kiosk associations allowed per layout depends on your CRM edition: - Standard / Professional: 1 association - Enterprise: 3 associations - Ultimate and above: 5 associations
  - [Examples](operations/updateKioskAssociations/examples/)
- [Kiosk CurrentRecords Associations ](operations/getKioskCurrentRecordAssociations/operation.md)
  - To retrieve all associations configured for the current record of the specified kiosk in your Zoho CRM organization. Use this API to retrieve all the associations configured for the CurrentRecord lookup field in a specific Kiosk. It returns the list of associated resources, including their sequence, name, and ID, that are linked to the CurrentRecord in the Kiosk setup. **Note:** - The response includes all associations defined for the CurrentRecord in the specified Kiosk. - Each association may contain one or more resources with details such as sequence number, name, and ID.
  - [Examples](operations/getKioskCurrentRecordAssociations/examples/)
- [Kiosk Associations](operations/getAllKiosksAssociations/operation.md)
  - To retrieve association information for all kiosks in your Zoho CRM organization, including detail view page associations with linked layout and module details. Use the [Get All Kiosks API](kiosks.yaml#$.paths./settings/kiosks.get) to retrieve the Kiosk ID. **Note:** - The structure of each resource object is mostly consistent, but _details can vary. - The sequence_number plays an important role in determining execution or display order.
  - [Examples](operations/getAllKiosksAssociations/examples/)
