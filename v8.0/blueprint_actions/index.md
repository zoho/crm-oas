# Blueprint Actions API

- [OpenAPI specification](blueprint_actions.yaml)
- [Get Blueprint transitions of a record](operations/getRecordBlueprintTransition/operation.md)
  - To get the next available Blueprint transitions for a record in Zoho CRM, along with the fields available for each transition, the current value of each field, and their validations, if any.
  - [Examples](operations/getRecordBlueprintTransition/examples/)
- [Update a single Blueprint transition for a record](operations/putRecordBlueprintTransition/operation.md)
  - To update a single Blueprint transition for a record in your Zoho CRM organization.
  - [Examples](operations/putRecordBlueprintTransition/examples/)
