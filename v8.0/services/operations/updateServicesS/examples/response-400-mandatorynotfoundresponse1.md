MANDATORY_NOT_FOUND error when a required service field is missing from the request

```json
{
  "data": [
    {
      "code": "MANDATORY_NOT_FOUND",
      "message": "Required field is missing",
      "details": {
        "api_name": "id",
        "json_path": "$.data[*].id"
      },
      "status": "error"
    }
  ]
}
```
