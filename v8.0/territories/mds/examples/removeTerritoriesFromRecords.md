# Examples: removeTerritoriesFromRecords

**POST /{module}/actions/remove_territories**

## Request examples

### `application/json` — RemoveTerritoriesSuccess

Remove territories from multiple records

```json
{
  "data": [
    {
      "id": "456789098764332",
      "Territories": [
        {
          "id": "423456712345623"
        }
      ]
    }
  ]
}
```

