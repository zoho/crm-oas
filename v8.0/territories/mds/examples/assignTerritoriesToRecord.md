# Examples: assignTerritoriesToRecord

**POST /{module}/{record}/actions/assign_territories**

## Request examples

### `application/json` — AssignTerritoryByRecordId

Territory assignment request for a single record

```json
{
  "data": [
    {
      "Territories": [
        {
          "id": "123456712345623456"
        },
        {
          "id": "123456712345623467"
        }
      ]
    }
  ]
}
```
