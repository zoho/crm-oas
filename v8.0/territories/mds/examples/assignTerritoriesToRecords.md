# Examples: assignTerritoriesToRecords

**POST /{module}/actions/assign_territories**

## Request examples

### `application/json` — SuccessTerritoryAssign

Assign territories to multiple records

```json
{
  "data": [
    {
      "id": "record id",
      "Territories": [
        {
          "id": "123456712345623456"
        },
        {
          "id": "123456712345623467"
        }
      ]
    },
    {
      "id": "record id",
      "Territories": [
        {
          "id": "123456712345623456"
        },
        {
          "id": "123456712345623467"
        }
      ]
    }
  ]
}
```
