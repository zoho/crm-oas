# Examples: removeTerritoriesFromRecord

**POST /{module}/{record}/actions/remove_territories**

## Request examples

### `application/json` — RemoveTerritoriesSuccess

Remove territories from a single record

```json
{
  "data": [
    {
      "Territories": [
        {
          "id": "123456712345623456"
        },
        {
          "id": "123456712345623467"
        }
      ]
    }
  ]
}
```
