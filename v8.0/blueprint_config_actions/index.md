# Blueprint Config Actions

- [OpenAPI specification](blueprint_config_actions.yaml)
- [Reorder Blueprints within a module ](operations/reorderBlueprints/operation.md)
  - To update the display order of Blueprints within a Zoho CRM module, submit a list of Blueprint entries each specifying an ID and the desired sequence_number. The operation accepts up to 100 entries per request and returns the outcome for each Blueprint, indicating whether its position update succeeded.
  - [Examples](operations/reorderBlueprints/examples/)
- [Retrieve Blueprint stage record counts ](operations/getBlueprintRecordsCount/operation.md)
  - To retrieve the number of records at each Blueprint stage for a specific Blueprint in your Zoho CRM organization.
  - [Examples](operations/getBlueprintRecordsCount/examples/)
