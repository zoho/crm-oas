# Change Owner

- [OpenAPI specification](change_owner.yaml)
- [Change Owner](operations/changeSingleRecordOwner/operation.md)
  - To change the owner of a specific record in the specified CRM module in your Zoho CRM organization. Note: The module name `Deals` is accepted and internally resolved to `Potentials`. `Meetings` is internally resolved to `Events`.
  - [Examples](operations/changeSingleRecordOwner/examples/)
- [Change Owner](operations/changeOwnerBulk/operation.md)
  - Updates the owner of multiple records in the module. Note: The module name `Deals` is accepted and internally resolved to `Potentials`. `Meetings` is internally resolved to `Events`.
  - [Examples](operations/changeOwnerBulk/examples/)
