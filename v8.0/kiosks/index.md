# Kiosks

- [OpenAPI specification](kiosks.yaml)
- [Get All Kiosks ](operations/getAllKiosks/operation.md)
  - To retrieve all the available Kiosks in your Zoho CRM organization. The response includes metadata for each Kiosk, such as version information, associated module, current status, creator and modifier details, and record context, if configured.
  - [Examples](operations/getAllKiosks/examples/)
- [Create a Kiosk ](operations/createKiosk/operation.md)
  - To create a new Kiosk in the draft state in your Zoho CRM organization. After creating the Kiosk, use the [Create a Kiosk State API](kiosks_states.yaml#$.paths./settings/kiosks/{kioskId}/states.post) to configure screens and then use the [Activate Kiosk API](kiosks.yaml#$.paths./settings/kiosks/{kioskId}/actions/activate.put) to publish it. Available in the Standard, Professional, Enterprise, and Ultimate editions. **Note:** - Using this API, you can only create a kiosk in a single API call. The created Kiosk will remain in the draft state. - Refer to the [Compare all features of Zoho CRM editions document](https://www.zoho.com/crm/complete-feature-list.html) to know edition-specific limits for Kiosk creation.
  - [Examples](operations/createKiosk/examples/)
- [Kiosk Deletion](operations/bulkDeleteKiosks/operation.md)
  - To delete one or more Kiosks from your Zoho CRM account. Use the [Get Kiosks API](kiosks.yaml#$.paths./settings/kiosks.get) to retrieve Kiosk IDs. **Note:** You can delete: - Draft Kiosks. - Deactivated Kiosks. - Published Kiosks that are not associated with any supported locations, such as the Home Page, Setup Page, Custom Buttons, or the Record Details View. Available in the Standard, Professional, Enterprise, and Ultimate editions.
  - [Examples](operations/bulkDeleteKiosks/examples/)
- [Get a Specific Kiosk](operations/getKiosk/operation.md)
  - To retrieve the details of a specific kiosk in your Zoho CRM organization, identified by its unique kiosk ID. Use the [Get Kiosks API](kiosks.yaml#$.paths./settings/kiosks.get) to retrieve Kiosk ID.
  - [Examples](operations/getKiosk/examples/)
- [Update a Kiosk ](operations/updateKiosk/operation.md)
  - To update an existing **draft** Kiosk in Zoho CRM. This API allows you to update the Kiosk's name, description, group API name, and current record module. Use the [Get All Kiosks API](kiosks.yaml#$.paths./settings/kiosks.get) to retrieve the Kiosk ID. You can identify a draft Kiosk using the status key in the response, where the value will be draft. **Note:** - You can update **one** Kiosk in a single API call. - All fields supported in the [Create a Kiosk API](kiosks.yaml#$.paths./settings/kiosks.post) can be updated using this API. - You can update a Kiosk only when it is in the draft state. Availability: Standard, Professional, Enterprise, and Ultimate editions.
  - [Examples](operations/updateKiosk/examples/)
- [Delete a kiosk](operations/deleteKiosk/operation.md)
  - To delete an existing Kiosk from your Zoho CRM organization. The deletion removes the entire Kiosk entry, including all states created within it, along with any related data. You can delete Draft Kiosks, Deactivated Kiosks, and Published Kiosks that are not associated with any supported locations, such as the Home Page, Setup Page, Custom Buttons, or the Record Details View. Use the [Get Kiosks API](kiosks.yaml#$.paths./settings/kiosks.get) to retrieve Kiosk ID. Available in: Standard, Professional, Enterprise, and Ultimate editions. **Note:** You can delete: - Draft Kiosks - Deactivated Kiosks - Published Kiosks that are not associated with any supported locations, such as the Home Page, Setup Page, Custom Buttons, or the Record Details View.
  - [Examples](operations/deleteKiosk/examples/)
- [Clone a Kiosk ](operations/cloneKiosk/operation.md)
  - To clone an existing kiosk in Zoho CRM and create a new one from it. Cloning lets you reuse the full structure and configuration of a kiosk — including all its states, transitions, screens, actions, and decisions — without rebuilding it from scratch. The cloned kiosk can be created as an independent, standalone kiosk or as a draft version linked to the source kiosk. This API copies the source kiosk exactly as it is; it does not support modifying the kiosk's configuration during the cloning process. To make changes to the cloned Kiosk after it is created, use the [Update a Kiosk State API](kiosks.yaml#$.paths./settings/kiosks/{kioskId}.put). Available on Standard, Professional, Enterprise, and Ultimate editions.
  - [Examples](operations/cloneKiosk/examples/)
- [Activate Kiosk ](operations/activateKiosk/operation.md)
  - To activate a Kiosk that is in draft or inactive state in Zoho CRM. The Kiosk must contain at least one screen before it can be activated. Once activated, the Kiosk becomes active and can be used for data collection. Activate a Kiosk after configuring its states and before using the [Execute a Kiosk API](kiosks_execute.yaml#$.paths./settings/kiosks/{kioskId}/actions/execute.post). A Kiosk can be in one of three states: draft - Not yet activated active - Currently live and in use inactive Previously active and later deactivated. Use the [Get All Kiosks API](kiosks.yaml#$.paths./settings/kiosks) to retrieve the Kiosk ID. You can activate only a Kiosk that is in the draft or inactive state. Use the Get a [Specific Kiosk API](kiosks.yaml#$.paths./settings/kiosks/{kioskId}.get) to check the current status of the Kiosk from the status key in the response. Example: "status": "draft" **Note:** - A Kiosk must contain at least **one** screen to be activated. - Use the [Create a Kiosk State API](kiosks_states.yaml#$.paths./settings/kiosks/{kioskId}/states.post) to configure and add the necessary components before calling the [Activate Kiosk API](kiosks.yaml#$.paths./settings/kiosks/{kioskId}/actions/activate.put). Availability: Standard, Professional, Enterprise, and Ultimate editions.
  - [Examples](operations/activateKiosk/examples/)
- [Deactivate a Kiosk](operations/deactivateKiosk/operation.md)
  - To deactivate an active Kiosk in your Zoho CRM account. Once deactivated, the Kiosk will no longer be accessible for users. Use the [Get All Kiosks API](kiosks.yaml#$.paths./settings/kiosks) to retrieve the Kiosk ID. **Note** - A Kiosk must be in the Active (Published) state before it can be deactivated. After deactivation, its status changes to inactive. To make the Kiosk active again, use the [Activate Kiosk API](kiosks.yaml#$.paths./settings/kiosks/{kioskId}/actions/activate.put). - You cannot deactivate a Kiosk that has existing associations. For example, if the Kiosk is associated with the Record Details View or any other supported component, you must remove those associations before deactivating the Kiosk.
  - [Examples](operations/deactivateKiosk/examples/)
