# Cadence Execution

- [OpenAPI specification](cadences_execution.yaml)
- [Enroll Records to Cadences](operations/postEnrolInCadences/operation.md)
  - Enrolls CRM records into one or more cadences. **Notes** - Only Manual Enrollment cadences can be enrolled through this API. - Available only in Enterprise edition and above. - Supports Leads, Contacts, Deals, Vendors, and custom modules. - A request may contain up to 5 cadence IDs. - A request may contain up to 100 record IDs.
  - [Examples](operations/postEnrolInCadences/examples/)
- [Un-enroll Records from Cadences](operations/postUnenrolFromCadences/operation.md)
  - To manually unenroll records of a supported module from one or more Cadences in your Zoho CRM organization.
  - [Examples](operations/postUnenrolFromCadences/examples/)
