# Wizards

- [OpenAPI specification](wizards.yaml)
- [Get all wizard configurations](operations/getAllWizards/operation.md)
  - To retrieve the wizard configurations available in your Zoho CRM organization. The response can be filtered by module using the `**module**` query parameter.
  - [Examples](operations/getAllWizards/examples/)
- [Wizards](operations/createWizard/operation.md)
  - Creates a wizard configuration for a specified module.
  - [Examples](operations/createWizard/examples/)
- [Get wizard details](operations/getWizardDetails/operation.md)
  - To retrieve the complete configuration of a single wizard in your Zoho CRM organization, including its containers, screens, segments, buttons, and conditional rules.
  - [Examples](operations/getWizardDetails/examples/)
- [Wizard](operations/updateWizard/operation.md)
  - Updates the specified wizard including screens, containers, field configurations, and rules - based on the data provided in the request.
  - [Examples](operations/updateWizard/examples/)
- [Wizard](operations/deleteWizards/operation.md)
  - Deletes the specified wizard configuration.
  - [Examples](operations/deleteWizards/examples/)
